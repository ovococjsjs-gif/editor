# Архив

Материалы предыдущих итераций работы над книгой. В рабочей области они не
нужны: актуальные версии лежат в корне репозитория. Ничего не удалено —
всё перенесено сюда без изменений, git хранит полную историю.

## Структура

| Папка | Что внутри | Почему в архиве |
|---|---|---|
| `01_главы_старые/` | `Глава_01.docx`, `Глава_01 (ред).docx`, `Глава_02.docx`, `Глава_02 (ред).docx` | Промежуточные версии глав; актуальные — `Глава_01_ready.docx`, `Глава_02_wip.docx`, `Глава_03.docx` |
| `04_справка_календарь/` | `КАЛЕНДАРЬ.md` | Самостоятельная справка по календарю; данные вошли в `writing-craft/references/world-units.md` |

Была также папка `02_разборы_и_диагнозы/` (разборы и диагнозы прошлой редакторской
сессии) — удалена по решению автора: выводы из них уже учтены в пакете
`writing-craft/`. Старый большой скилл `SKILL-writing-craft (1).md` по решению
автора возвращён в корень как справочник с калибровочными примерами (рабочий
канон — пакет `writing-craft/`).

## Как вернуть

Строка из git:

```
git checkout HEAD -- путь/к/файлу
```

или просто перенести файл обратно в корень.
