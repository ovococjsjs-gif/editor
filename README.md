# Редакторский репозиторий

## Структура

- `manuscript/` — сохранённые авторские версии глав.
- `publication/` — отдельные редакторские версии, подготовленные к публикации,
  и журналы изменений.
- `project-context/` — библия проекта, календарь и сведения о мире. Основной
  рабочий источник без сюжетных спойлеров —
  `project-context/СПРАВОЧНИК_МИРА_БЕЗ_СПОЙЛЕРОВ.md`; полная библия открывается
  только по отдельной необходимости.
- `prior-analysis/` — прежние разборы, изолированные от независимого чтения.
- `editorial/` — новые редакторские разборы, сделанные в текущей работе.
- `writing-craft/` — рабочий пакет редакторского skill.
- `skill-materials/` — исходные и аналитические материалы, относящиеся к skill.

## Актуальная рукопись

1. `manuscript/Глава_01_ready.docx`
2. `manuscript/Глава_02_wip.docx`
3. `manuscript/Глава_03.docx`

Предыдущие варианты глав удалены из рабочей структуры, но сохраняются в истории Git.

## Режим независимого чтения

Чтобы редактор видел текст глазами нового читателя:

1. сначала читается только рукопись из `manuscript/`;
2. непонятные места фиксируются без попытки восстановить авторский замысел по внешнему контексту;
3. `project-context/` открывается только после первичного читательского прохода;
4. `prior-analysis/` не используется до завершения собственного разбора;
5. замечания разделяются на читательские затруднения, редакторские диагнозы и варианты правки.

Текущий статус: структура приведена в порядок; рабочий skill пересмотрен;
главы 1–2 прочитаны, обсуждены с автором и отредактированы в отдельные
публикационные версии. Получен и обновляется бесспойлерный справочник мира.
Полная библия, календарь, глава 3 и прежние разборы глав ещё не читались.
