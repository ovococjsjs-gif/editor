# Проза «Хроник Этериума»

Голос ставится по образцу, а не по списку запретов. Порядок работы: сначала
прочитать корпус, потом писать, потом мерить скриптами.

## Закон

ИИ пишет **закрыто**: каждое движение доведено до конца, каждая сцена
закрыта выводом, каждый персонаж договаривает. Автор пишет **открыто**:
действие не удаётся с первого раза, вывод кривой или его нет, человек не
договаривает главного.

Всё остальное в этом пакете — следствия.

## Шаг 1. Читать корпус

[references/voice-corpus.md](references/voice-corpus.md) — восемь размеченных
фрагментов принятого текста. **Читать перед первой сценой целиком.** Дальше
брать ближайший по типу образец:

| Задача | Образец |
|---|---|
| бытовая сцена, где ничего не происходит | 1 |
| выдать сведения о мире | 2, 4, 7 |
| показать близость двух людей | 1, 3, 6 |
| спор без крика | 5 |
| длинная реплика | 2, 6 |
| эпизодический голос | 2, 4, 7 |
| работа POV по профессии | 7, 8 |

Разметку не пересказывать в тексте — воспроизводить ход.

## Шаг 2. Писать

При письме держать в голове только это:

| Инстинкт модели | Ход |
|---|---|
| в ссоре объявить позицию | проверить связь: обращение, вопрос, общее прошлое |
| дать красивое сравнение | пометить «казалось», обернуть против сравнившего |
| вложить в реплику обобщение | адресат + жест + сомнение POV |
| герой сделал и получилось | не вышло с первого раза; тело мешает мысли |
| объяснить мир ровно | говорящий спотыкается на больном слове |
| «она поняла, что…» | «возникла мысль, что, возможно» + кривая концовка |
| все говорят одинаково | у каждого своя речевая стратегия |
| приём удался — повторить | у каждого приёма потолок на главу |

Четыре регистра подачи, каждый хотя бы раз на главу: прямая речь, косвенная
речь, сводка-пересказ, внутренний счёт наблюдателя.

Числа: POV называет только то, что получил счётом, телом, от людей или по
ремеслу. Часов нет — минут нет; время идёт колоколами, сроки декадами.

Подробности и разбор дефектов — [references/defects.md](references/defects.md).
Единицы, деньги, календарь, кто есть кто —
[references/world-units.md](references/world-units.md).

## Шаг 3. Мерить

```
python3 scripts/tics.py   Глава_XX.docx --list
python3 scripts/ladder.py Глава_XX.docx --list
python3 scripts/range.py  Глава_XX.docx --list
```

Скрипты принимают `.docx` и `.txt`. Ненулевой код возврата — есть превышения.

Ключевые пороги (полностью — [references/norms.md](references/norms.md), все
числа посчитаны по принятому тексту):

- серия реплик подряд ≤ 6 (блокер > 8); реплик внутри лесенок ≤ 40 %;
- реплик короче четырёх слов ≤ 45 %;
- реплик по 40+ слов ≥ 3 на главу;
- многоточий-обрывов ≥ 3; «действие не удалось» ≥ 2; «POV не ручается» ≥ 4;
- потолки приёмов: «сказал это» ≤ 4, «как + делают вообще» ≤ 4,
  «без + отвлечённое сущ.» ≤ 6, «раньше/прежде, чем» ≤ 3,
  «и это было» ≤ 2, пуант ≤ 14, триада ≤ 10;
- доля трёх самых частых начал абзаца ≤ 34 %; подряд с одного слова ≤ 3.

**Петля:** прогнать → починить конкретные находки (`--list` даёт номера
абзацев) → прогнать снова. Не переписывать сцену целиком из-за одного
превышения: убрать лишние повторы приёма, а не сам приём.

Недобор по квоте — такой же дефект, как перебор. Если многоточий ноль, а
длинных реплик одна, текст ровный и мёртвый, даже когда все потолки соблюдены.

## Шаг 4. Сдать

Чеклист сдачи, ружья, проверка знания персонажей, ломка структуры —
[references/continuity.md](references/continuity.md). Скопировать чеклист в
ответ и отметить пункты.

## Чего скрипты не ловят

Прохождение всех трёх скриптов не означает, что глава хорошая — только что в
ней нет известных дефектов. Живость проверяется корпусом, связность —
чтением. Если текст прошёл метрики и всё равно читается мёртвым, причина
почти всегда одна: сцена закрыта, всё договорено, никто не ошибся.
